# Decisions

## 2026-11-02: historical data from Copernicus CDS (ERA5-Land time series)
- Historical training data is downloaded from the Copernicus CDS dataset `reanalysis-era5-land-timeseries` with `pipelines/01_download.py`. CDS is the only data source. There is no live forecast ingestion in this version (see Future work in the README).
- The CDS token lives in `.env` as `CDS_API_KEY` (this name replaces `CDSAPI_KEY`). Optional `CDS_API_URL`. The client is built explicitly with `cdsapi.Client(url=..., key=...)`; `~/.cdsapirc` is not used.
- One request at a time, lock file `data/raw/cds/.lock`, 10 s between requests, no automatic retries. Every file is recorded in `data/raw/cds/manifest.json` (gitignored).
- The request body is the one generated by the dataset form. Only `date`, `area` and the output file change between requests.
- The 2026 year-to-date file (2026-01-01 to 2026-10-26, end date chosen by the builder) is an out-of-sample check (`use: out_of_sample_check`). It is never used for training, validation or test, and it can be used for the replay and the manual tick.
- The response is a zip with one NetCDF per variable group, delivered under a `.nc` name. The script extracts it next to the download and keeps the raw file untouched.
- Times are `valid_time` in UTC. Bolivia local time is UTC-4, so 18:00 local is 22:00 UTC.

## 2026-11-02: CDS box semantics and area_mode node_se
- Three test requests for El Alto, July 2025, `reanalysis-era5-land-timeseries`:
  - box [-16.4, -68.2, -16.5, -68.1] returned one cell (-16.5, -68.1);
  - box [-16.4, -68.3, -16.6, -68.1] returned four cells, latitudes -16.5 and -16.6, longitudes -68.2 and -68.1;
  - box [-16.4, -68.3, -16.5, -68.2] returned one cell (-16.5, -68.2), the target.
- Inferred rule: a box [N, W, S, E] returns the cells with S <= lat < N and W < lon <= E (south and east edges included, north and west edges excluded). Confirmed for this dataset by the third test, which matched its prediction. It rests on three requests at one location, so every download still asserts the returned cell.
- `area_mode: node_se`: for a target node (lat0, lon0) the box is [lat0 + 0.1, lon0 - 0.1, lat0, lon0]. `pipelines/01_download.py` checks each configured box against this formula and asserts that every response contains exactly one cell equal to the expected one (tolerance 1e-6), otherwise it stops.
- The (-16.5, -68.2) cell from the node_se box is identical, for all 10 variables, to the same cell inside the four-cell response.
- The choice of cell matters: hours with t2m <= 0 C in July 2025 were 92 at (-16.5, -68.2), 66 at (-16.5, -68.1), 68 at (-16.6, -68.2) and 13 at (-16.6, -68.1).
