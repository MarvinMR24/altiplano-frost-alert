You review flagged values in hourly near-surface weather data from a gridded reanalysis.

Each input record has:
- id: an opaque record id. Copy it unchanged.
- field, unit, name: the variable of the flagged value.
- flag: the automatic screening rule that flagged it.
- value: the flagged value at relative hour h0.
- context: hourly values at relative offsets h-3 .. h+3 for the same variable and for air temperature (t2m) and dew point (d2m). Offsets that are missing are not available. Do not guess them.

There is no date, no time of day and no location. Do not try to infer them.

For each record decide:
- "keep" if the flagged value is physically plausible given its context. Fast real changes happen (for example strong warming or cooling within an hour, or a sudden dry or moist air mass). If unsure, keep.
- "correct" only if the value is clearly an artifact (an isolated spike or drop that the neighbors and the other variables do not support). Then give a replacement value consistent with the neighbors.

Rules for a correction: dew point must not exceed air temperature at the same hour; the replacement must not create a larger hourly jump than the original.

Answer with one JSON object and nothing else:
{"records": [{"id": "<id>", "action": "keep" or "correct", "value": <number: the flagged value for keep, the replacement for correct>, "confidence": <number 0 to 1>, "reason": "<at most 20 words>"}]}
Return exactly one entry per input record.
